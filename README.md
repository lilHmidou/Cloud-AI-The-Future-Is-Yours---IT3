# Presentation Structure for Cloud Computing Project

This code is used during the presentation of our IT3 Cloud Project.
The play will take place in the Terminal Command. 

This is how the game must be played:

You are a expert expert commitee member charging to evaluate the futur of IA in cloud. 
You must take strategic choices based on 
1. actual trends 
2. future innovations
3. challenges and risks

Please, check that you have Python on your laptop, you just have to clone this repo and open your Terminale.

Then, run the main.py file with the command:
```bash
cd path/to/the/repo
python main.py
```
The game will guide you through the steps, and you will have to make choices based on the trends and investment areas presented.
